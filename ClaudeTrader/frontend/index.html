ClaudeTrader ships a strategy framework with a shared base interface, an event-driven backtester and risk-managed entry/exit protocols. The strategies below are implemented in strategies/__init__.py.

Implemented Strategies

SuperTrend
ATR-based dynamic support/resistance trend following with index-aligned crossover detection.
trend
Multi-Factor
Weighted blend of trend, momentum and volatility factor scores.
blended
Hybrid Ensemble
Confidence-weighted vote across multiple sub-strategies.
ensemble
RL Agent
Reinforcement-learning policy hook (pluggable model interface).
ml

Entry / Exit Protocols

ATR Stop-Loss & Take-Profit
Volatility-scaled protective stops and risk/reward-based targets (utils/risk.py).
risk
Fixed-Fractional Position Sizing
Sizes each trade so a stop-out risks a fixed fraction of equity (default 2%).
sizing
Trailing Stops
Ratcheting stop that only tightens in the favorable direction.
exit
R-Multiple Accounting
Expresses realized outcomes in units of initial risk.
analytics

The event-driven backtester (utils/backtest.py) replays OHLCV data bar by bar with commission and slippage, applies the risk protocols above, and reports a full performance metric set (utils/performance.py).

Run a Backtest

from strategies import SuperTrendStrategy
from utils.backtest import backtest_strategy
from utils.data_fetcher import fetch_market_data

data = fetch_market_data("BTC/USD", "1h", limit=2000)
strat = SuperTrendStrategy(
    {"parameters": {"atr_period": 10, "multiplier": 3.0}}
)
result = backtest_strategy(strat, data, {
    "commission_pct": 0.001,
    "slippage_pct": 0.0005,
    "risk_per_trade": 0.02,
    "trailing_stop": True,
})
print(result["performance"])
